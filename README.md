# Guess The Flag

Project 3 of the [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui)  challenge—a guessing game built with Swift and SwiftUI that helps users learn flags of different countries around the world.

## 🛠️ Concepts Covered

* **`@State` property wrappers** for managing game state, user score, and alert display logic
* **`VStack`, `HStack`, and `ZStack`** for layout composition and background styling
* **`Image` & `Button` views** for creating interactive flag selection buttons
* **`LinearGradient` & Color Modifiers** for building custom iOS visual styles
* **Custom Alert Dialogs** to show feedback on correct or incorrect choices and update scores in real-time
